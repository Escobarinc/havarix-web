# HAVARIX – web (testovací náhled)

Rozpracovaný web HAVARIX: havarijní pohotovost, vysoušení staveb a půjčovna techniky.

- Web: `index.html`, podstránky `page.html?view=…`
- Půjčovna: `page.html?view=pujcovna`
- Administrace: `admin.html`

**Testovací režim:** formuláře zatím nic neodesílají a administrace ukládá jen do prohlížeče, ve kterém se používá. Web není určený k indexování (noindex). Ostré odesílání, ukládání na server a přihlášení se doplní před spuštěním.
